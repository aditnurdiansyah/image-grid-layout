# Image Grid Layout

## Project Overview

This project involves creating a modern, visually compelling, and responsive **Image Grid Layout** component using semantic HTML and modern CSS Grid techniques. The primary objective is to build an interactive image gallery grid that effectively organizes visual content while maintaining seamless responsive behavior across all device viewports.

The project focuses on building a semantic web gallery while applying essential frontend practices such as CSS Grid layout architecture, image accessibility (`alt` attributes and semantic `<figure>` elements), SEO meta tags, Open Graph (OG) integration for social sharing, favicon implementation, Google Fonts integration, and responsive layout optimization.

## Project Requirements

* **CSS Grid Structure & Item Placement**
  Utilize CSS Grid container properties and item placement properties to construct a structured, balanced grid layout based on design specifications.

* **Semantic HTML & Image Accessibility**
  Use semantic elements along with descriptive alt text to ensure full accessibility for screen readers and optimal document hierarchy.

* **Search Engine Optimization (SEO) Meta Tags**
  Include essential metadata inside the `<head>` section to improve discoverability and search engine indexing.

* **Open Graph (OG) Tags**
  Implement Open Graph tags to provide optimized previews when sharing links on social media platforms.

* **Favicon**
  Add a favicon for better branding and browser recognition.

* **Responsive Layout Preparation**
  Organize the layout using CSS Grid and media queries to seamlessly adapt from multi-column desktop arrangements down to single-column mobile views.

* **Alignment, Spacing & Interactive States**
  Manage grid item alignment, aspect ratios, image cropping, and interactive hover/focus states to deliver a polished visual experience.

## Project Structure

* **Homepage (`index.html`)**
  The primary HTML document containing semantic gallery markup, image items, figure containers, captions, and structural containers.

* **Styles (`css/style.css`)**
  Contains custom CSS styling, CSS Grid layout definitions, gap spacing, hover effects, object-fit rules, and responsive breakpoints.

* **Assets (`assets/`)**
  Directory containing project images, favicons, Open Graph images, and `project-preview.png`.

## How to Use

1. Clone or download this repository.

```bash
git clone https://github.com/aditnurdiansyah/image-grid-layout
```

2. Navigate to the project folder.

```bash
cd image-grid-layout
```

3. Open `index.html` in your browser.

4. Customize the styling, grid track definitions, and image items according to your layout requirements.

This project provides practical experience in designing and building a responsive, visually appealing Image Grid Layout component using CSS Grid and clean, semantic HTML.
